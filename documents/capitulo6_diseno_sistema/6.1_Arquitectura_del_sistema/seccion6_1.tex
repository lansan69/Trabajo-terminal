Para documentar la arquitectura del sistema se utiliza el modelo C4, propuesto por Simon Brown entre 2006 y 2011 \cite{}. Este modelo describe la arquitectura de software mediante diagramas jerárquicos que van de lo general a lo particular, de modo que cada nivel constituye un acercamiento del anterior. Define cuatro niveles de abstracción: contexto, contenedores, componentes y código. En este trabajo se emplean los tres primeros, dado que el nivel de código es opcional y su detalle puede obtenerse directamente del código fuente.


\subsection{Diagrama de contexto}
El diagrama de contexto presenta el sistema como una sola caja, junto con los usuarios y los sistemas externos con los que interactúa \cite{}. La figura \ref{fig:diagrama_contexto} muestra el diagrama correspondiente al presente proyecto.
