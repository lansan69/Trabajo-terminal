A continuación se presenta el análisis de costos asociados al desarrollo del prototipo de aplicación móvil. Todos los costos se expresan en pesos mexicanos (MXN) y se acompañan de la fuente y fecha de consulta correspondiente.

\subsubsection{Recursos tecnológicos}

Para la realización del proyecto se contempla el uso de recursos de hardware, software y servicios en la nube. Todo el dimensionamiento se calcula para cubrir el periodo de 10 meses de desarrollo, con un tipo de cambio FIX estimado de \$17.9670 MXN por dólar estadounidense \cite{banxico_fix}.

\vspace{1mm}

\textbf{1. Hardware Comercial} 
El desarrollo y las pruebas exigen capital físico comercial. El presupuesto desglosa la infraestructura base en tres equipos de cómputo portátiles específicos valuados a precio de mercado actual: una \textit{Lenovo IdeaPad Flex 5 Gen 8 (AMD)} \cite{lenovo_flex5}, una\textit{ Lenovo IdeaPad Slim 3i (Intel)} \cite{lenovo_slim3i} y una\textit{ ASUS Vivobook 14 (X1404)} \cite{asus_vivobook}. Asimismo, aunque para la validación de los sensores (GPS) únicamente se requiere un dispositivo estándar con sistema operativo Android, se integra al presupuesto el valor comercial del equipo inteligente con el que se cuenta para dichas pruebas físicas: un\textit{ Honor Magic6 Lite 5G} \cite{telcel_honor}.

\textbf{2. Software, Base de Datos y Ruteo (Capa Gratuita)}
Para el desarrollo móvil se emplea el \textit{framework} Flutter (Dart). La obtención de la red vial se auxilia en OpenStreetMap (OSM) bajo licencia ODbL sin costo \cite{osm_legal_pricing}. La gestión de datos y ruteo geoespacial (PostgreSQL, PostGIS, pgRouting) utiliza Supabase:
\begin{itemize}
    \item \textbf{Justificación de cuota:} El plan gratuito ofrece 500 MB de base de datos \cite{supabase_pricing}. El polígono de estudio (26.31 km\textsuperscript{2}) comprende $\approx$3,500 segmentos de calle. Con un peso de 1 a 3 KB por segmento, el volumen estimado se ubica entre 3.5 y 10.5 MB, garantizando su viabilidad dentro del límite sin generar costo.
\end{itemize}

\textbf{3. APIs de Preprocesamiento de Datos (Costo Base)}
\begin{itemize}
    \item \textbf{Google Street View Static API:} Se obtendrán máximo tres imágenes por cada segmento de calle, generando 10,500 solicitudes. La API ofrece 10,000 mensuales gratuitas. Las 500 solicitudes facturables (a \$7.00 USD por cada 1,000 extra) generan un costo conservador de \$3.50 USD (\$62.88 MXN) \cite{google_maps_pricing}.
    \item \textbf{Qwen3.7-Flash:} El análisis de imágenes consume $\approx$2,000 tokens de entrada (\$0.03 USD/M) y 500 de salida (\$0.13 USD/M) por imagen. Las 10,500 imágenes requieren 21M tokens de entrada y 5.25M de salida, con un costo total de \$1.31 USD (\$23.58 MXN) \cite{qwen_pricing}.
\end{itemize}

\textbf{4. Servicios Externos de Operación (Capa Gratuita)}
Durante la operación del prototipo, se integran herramientas sin costo mensual: 
\begin{itemize}
    \item \textbf{Mapas y Búsqueda:} \texttt{maplibre\_gl} con teselas de OpenFreeMap (sin límite de uso) y Geoapify con 3,000 créditos diarios gratuitos (Photon como respaldo).
    \item \textbf{Notificaciones y Correo:} Firebase Cloud Messaging (FCM) sin costo \cite{firebase_pricing} y Resend con 3,000 correos mensuales \cite{resend_pricing}. El dominio propio para envío se obtiene gratuitamente el primer año con GitHub Student Developer Pack \cite{namecom_student}.
\end{itemize}

Adicionalmente, se incluyen servicios por suscripción mensual, contemplando las herramientas de apoyo operativo Overleaf \cite{overleaf_pricing} y Udemy \cite{udemy_pricing}, multiplicados por los 10 meses de desarrollo, consolidando los costos en la Tabla \ref{tab:recursos_tecnologicos}.
